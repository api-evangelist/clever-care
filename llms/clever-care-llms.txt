# Clever Care Health Plan

> Clever Care Health Plan is a California Medicare Advantage (HMO and HMO C-SNP) plan headquartered in Huntington Beach, CA, blending Eastern and Western medicine. It exposes a standards-based HL7 FHIR R4 API surface for Patient Access, Provider Directory, and Drug Formulary data in compliance with the CMS Interoperability and Patient Access rule (CMS-9115-F). This llms.txt was generated by API Evangelist from the provider's public developer resources.

## APIs

- [FHIR Patient Access, Provider Directory & Drug Formulary](https://fhir.clevercarehealthplan.com/r4): HL7 FHIR R4 gateway (WSO2). 13 published resource APIs at https://fhir.clevercarehealthplan.com/r4/{Resource}
- [Patient (secured)](https://fhir.clevercarehealthplan.com/r4/Patient): CARIN BB member demographics; SMART on FHIR patient context
- [ExplanationOfBenefit (secured)](https://fhir.clevercarehealthplan.com/r4/ExplanationOfBenefit): CARIN BB claims and encounters
- [Coverage (secured)](https://fhir.clevercarehealthplan.com/r4/Coverage): CARIN BB coverage
- [Organization](https://fhir.clevercarehealthplan.com/r4/Organization): PDex Plan-Net provider directory (public, rate-limited)
- [Practitioner](https://fhir.clevercarehealthplan.com/r4/Practitioner) / [PractitionerRole](https://fhir.clevercarehealthplan.com/r4/PractitionerRole)
- [Location](https://fhir.clevercarehealthplan.com/r4/Location) / [HealthcareService](https://fhir.clevercarehealthplan.com/r4/HealthcareService) / [InsurancePlan](https://fhir.clevercarehealthplan.com/r4/InsurancePlan)
- [OrganizationAffiliation](https://fhir.clevercarehealthplan.com/r4/OrganizationAffiliation) / [Endpoint](https://fhir.clevercarehealthplan.com/r4/Endpoint)
- [MedicationKnowledge](https://fhir.clevercarehealthplan.com/r4/MedicationKnowledge) / [List](https://fhir.clevercarehealthplan.com/r4/List): Da Vinci US Drug Formulary (public)

## Auth

- SMART on FHIR (OAuth 2.0 / OpenID Connect) for secured Patient Access resources; PKCE S256
- Authorize: https://fhir-portal.clevercarehealthplan.com/oauth2/authorize
- Token: https://fhir-portal.clevercarehealthplan.com/oauth2/token
- Scopes: openid, launch/patient, patient/*.cruds, user/*.cruds
